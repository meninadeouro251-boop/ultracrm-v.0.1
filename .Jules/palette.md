## 2025-05-15 - [Accessibility & Localization Standardization in Chat Input]
**Learning:** Icon-only buttons in complex UI components like `MessageInput` often lack consistent accessibility (missing `aria-label`) and utilize browser-native `title` instead of the design system's `Tooltip`. Additionally, localization keys for these global UI elements were either missing or hardcoded in specific locales.
**Action:** Centralize `TooltipProvider` at the root of the parent component to serve multiple child actions. Replace all native `title` attributes with localized `Tooltip` and `aria-label`. Ensure all interactive icon-only buttons have `type="button"` to prevent unintended form submissions. Always sync new UI-related localization keys across all supported locales (en, es, fr, it, pt, pt-BR).
