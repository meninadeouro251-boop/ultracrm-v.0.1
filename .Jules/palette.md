## 2025-05-14 - [Keyboard Shortcuts for Search]
**Learning:** In data-heavy CRM interfaces, common actions like searching can be significantly sped up with global keyboard shortcuts. Users expect familiar patterns like '/' to focus the search input, similar to GitHub or Slack. Providing a visual hint (KBD indicator) is crucial for discoverability and accessibility.
**Action:** Always consider adding a '/' shortcut to focus the primary search input on list pages, and ensure a non-intrusive visual indicator is present.
