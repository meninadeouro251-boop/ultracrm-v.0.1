## 2025-05-20 - [Accessibility Enhancement for Core Components]
**Learning:** Icon-only buttons in core shared components (BaseTable, BasePagination) frequently lacked both ARIA labels for screen readers and visible tooltips. Standardizing on the combination of `aria-label` and the design system's `Tooltip` component ensures accessibility and a better hover experience. Using interpolation in translation keys (e.g., `base.table.sort` with `{{column}}`) provides significantly better context for screen reader users.
**Action:** Always verify that icon-only buttons have both an `aria-label` and a `Tooltip`. When adding these to core components, ensure the corresponding translation keys are added to all supported locales (`en`, `es`, `fr`, `it`, `pt`, `pt-BR`) and use interpolation where dynamic context is available.
