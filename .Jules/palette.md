## 2025-03-24 - [Core Accessibility Pattern]
**Learning:** Established accessibility pattern for base components (Header, Pagination, Table, FilterRow) by defining standardized ARIA label keys in the `base` section of `common.json` across all locales.
**Action:** Use `base.pagination.previousPage`, `base.pagination.nextPage`, `base.header.moreActions`, `base.table.sort`, `base.table.moreActions`, and `base.filter.removeFilter` when adding accessibility to icon-only buttons in shared UI components.
